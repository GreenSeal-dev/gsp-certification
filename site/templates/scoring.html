Scoring

Each practice is assessed on its own scale. The score for the option chosen is multiplied by the practice's weight, and the weighted scores add up to a total for the level being assessed.

Assessment scale

Every practice lists the options an assessor can choose, from best to worst. Most practices use Implemented, Partially Implemented and Not Implemented.

By default, scores are spread evenly from 1 for the first option to 0 for the last. With three options that gives 1, 0.5 and 0. A practice can set its own scores instead.{% set custom = v.requirements|selectattr('custom_scoring')|first %}{% if custom %} For example, {{ custom.id }} scores {% for s in custom.scale %}{{ s.score|score }}{{ ", " if not loop.last and loop.revindex > 2 else (" and " if not loop.last else "") }}{% endfor %}.{% endif %} Each practice page lists the score for every option.

Weight

Each practice has a whole-number weight that reflects how much it contributes. The weighted score is the score multiplied by the weight. A practice with weight 3 that is partially implemented (score 0.5) contributes 1.5.

Totals per level

Priority

Practices are marked Core or Supporting. Completion rules can require a minimum number of Core practices in a category.

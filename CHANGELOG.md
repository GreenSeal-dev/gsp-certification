# Changelog

All notable changes to the GreenSeal Green Software Practices (GSP), maintained by [GreenSeal.dev](https://greenseal.dev), are listed here.

## [1.0.1] - 2026-10-28

Documentation only. The requirements are unchanged from 1.0.0.

- Add "GSP" to the list of GreenSeal, Lda. trademarks.
- State that GreenSeal.dev certifies organisations or teams against GSP, not products.
- Describe the requirements as reviewed against the six lifecycle phases of ISO/IEC TS 20125-1:2026, rather than aligned with them.

## [1.0.0] - 2026-10-28

First open release.
